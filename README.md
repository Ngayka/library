# Online Library Website

A web application for managing an online library, built with Django.
The project provides a convenient system for browsing and managing a book catalog with authentication, search, and filtering functionality.

### Features

* User authentication and authorization
* Book catalog database
* Search functionality for books
* Filtering by author or book title
* Backend built with Django
* Frontend implemented using Django Forms and Django Templates
* PostgreSQL database support (optional, if used)
* Responsive and user-friendly interface
* Tech Stack
* Python
* Django
* HTML/CSS
* Django Templates
* Django Forms
* PostgreSQL / SQLite

### Functionality

Users can:

* Register and log into the system
* Browse the library catalog
* Search for books by title
* Filter books by author
* View detailed information about books

### Installation

Clone the repository:

`git clone <repository_url>`
`cd <project_name>`

Create a virtual environment:

`python -m venv venv`

Activate the virtual environment:
Windows

`venv\Scripts\activate`

Linux / macOS

`source venv/bin/activate`

Install dependencies:

`pip install -r requirements.txt`

Run migrations:

`python manage.py migrate`

Start the development server:

`python manage.py runserver`
